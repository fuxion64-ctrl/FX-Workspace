# FX Workspace 1.4.8 - steadier, faster, and it sets itself up

**1.4.8 makes the app harder to break and much faster on local models.** It fixes the problems found in a full review of 1.4.7: a closed app that wouldn't open again, a setup that sent you to a terminal, chats that lost their start, replies that wrote and erased their first sentences, and long answers that were cut off. Local models now really use your graphics card when they can, and they get smaller requests - 9-27% fewer tokens to read, measured on a real model.

**Updating:** Settings › About › **Check now** › **Update now**, or press **Update** on Home when it offers one. From older versions, run `FX-Workspace-Setup-1.4.8.exe` over them. Your chats, settings, keys and models stay as they are.

## Speed

- **Local models use the graphics card again.** On one PC, an update had unpacked the model engine's NVIDIA files while the disk was full, and every model quietly ran on the processor - 4 words a second instead of 63. Setup now checks that the engine really sees your graphics card (and keeps the old engine if a new one doesn't), repairs an engine that can't, and checks there's room before it downloads. Diagnostics tells you when the engine can't use your graphics card.
- **Models that fit stay on the graphics card.** New models get a context size that fits beside them in its memory, instead of spilling into system memory, which was 4 times slower.
- **A live speed readout** at the top of the right panel shows words per second while a reply is being written.
- **The app starts faster:** the first answer is ready about 2.4 seconds after launch, down from 6. Closing takes 3 seconds instead of 20.
- **Smaller requests to local models:** a question carries only the tools and rules it needs - no Roblox rules in a chat about something else, no screen and file tools for a web question, no list of every open window for a greeting. Measured on a 9B model: 26-27% fewer tokens on web and voice questions, 9-12% on the rest.
- **Switching between a question and a web search no longer re-reads everything:** both start the same way, so the model reuses what it already read - about 3-4 times less to read on the switch.
- **One model call fewer before most replies:** the chat limits' check runs only when a message has words it could be about.

## Starting and setting up

- **The app opens again after it was closed.** A copy that got stuck while closing kept the app from starting - with no message - until Windows restarted. Now a stuck shutdown ends itself after 20 seconds, the desktop app closes a stuck earlier copy and starts, and the update closes it too.
- **Setup no longer sends you to a terminal.** If Python is missing, setup installs it by itself - python.org's own installer, checked by its signature, for your user only, no admin needed - and carries on.
- **The app finishes its own setup.** If its Python environment is missing or broken, the app sets itself up again on start, with each step on the start screen, instead of an error box.
- **A broken Python environment is rebuilt** and a failed package download is tried once more before setup gives up.

## Models

- **Choose where your models live.** Settings › Models › Models folder: pick any folder on any drive with Windows' own folder picker. Models already in the old folder keep working.
- **More model folders:** add folders for Scan to look in, with the folder picker.
- **Add a model file with Browse…** instead of typing its path.
- **Add a vision file (.mmproj) to a model you already have**, so it can see pictures - Browse… on the model's settings.
- **A model that keeps crashing the model engine is set aside by name** for 10 minutes, and the engine keeps running for your other models.
- **A big model reading a long chat** gets a longer wait for its first word, and a clear message if it runs out.
- **Compare no longer switches your chat** to the model you compared with.
- **Settings › Models opens faster.**

## Replies

- **Long answers aren't cut off.** A reply had room for about 2,000 tokens and simply stopped there - an HTML page ended halfway, even at Max. Now it has 8,000, a /design page 16,000, and an answer that still reaches the limit is continued where it stopped.
- **Replies no longer write and erase their first sentences.** When a small model starts by talking to itself ("The user said…, I should…"), that now shows as its thinking, not as the answer.
- **"Open Paint and draw a horse"** opens Paint and then draws, instead of looking for an app called "paint and draw a horse".
- **Links inside code** (an HTML page's fonts and scripts) are no longer listed as unchecked links.
- **Each reply's cost:** how many tokens the model read and how many it reused from its cache.
- **Conversation replies use each model's own settings;** the steady low temperature is kept for actions.
- **Stop works at once** while the app plans, reviews or sums up a task.
- **"Done - I created notes.txt" is no longer flagged** as an action the model made up.
- **A harmless message is no longer refused** when the checking model's answer can't be read.

## Chats

- **Long chats keep their start.** Only the last 400 messages used to be saved; now every message is, and older ones load as you scroll up. The model still reads only what fits.
- **A message can't land in the wrong chat** if another window or your phone switched chats meanwhile.
- **New chat can't wipe a reply** that is still being prepared.
- **A failure after the answer keeps the answer** instead of "Turn failed".
- **A "thinking" mark when you scroll up** during a reply; click it to jump back down.
- **Your page settings follow you** - theme, text size, sidebar and the rest survive the app moving to another port.

## Images

- **Opening Images no longer loads a model** you didn't ask for.
- **Adding a picture model doesn't start a test by itself:** you're offered a quick test instead.
- **The picture being made appears in the gallery grid,** in its own slot.

## Phone access

- **Phone access is an allow-list:** a new part of the app is reachable from your phone only once it is added on purpose.
- **After a message from your phone,** routines and later messages are treated as coming from the PC again.

## Smaller fixes

- The FX logo sits centred with the sidebar's icons.
- The picture viewer's buttons no longer throw errors.
- Every failed request is logged with its path, and the last three runs' logs are kept.
- The app answers "who's there" checks even when it's busy.
