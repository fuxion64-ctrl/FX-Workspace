# 1.4.6 - a walk-through as a user (stage 4.2, brief)

Done once, 4 Nov, at the end of 1.4.6, on the dev server (port 8010) with this build's screens - not with a live
model, so reply times aren't part of it. For each everyday job: the path, and what could still trip someone up.

| Job | Path now | Still unclear / for later |
|---|---|---|
| First start | Welcome: a chat model picked for this PC, Download, Skip | Fine. The download now shows speed and time left and can be paused |
| A normal chat | Type, Enter; the model loads the first time ("Loading … into memory") | The first reply waits for the model to load with no estimate; a "about N s" would help (1.5.0) |
| Deep research | Effort menu or ask for research; one card with progress and questions | One moving mark now. The card's source count is "~32" - the "~" reads as vague |
| Make a picture | Ask in the chat, or Images | Floating card, model picker on it, name a model in the chat. Picture speed/quality: 1.5.0 stage 5d |
| Add a model | Chat models: Settings › Models › Find models. Pictures: Settings › Images › Add | Two places for "add a model"; fine for now, one "Models" page for both is in the 1.5.0 Settings notes |
| Hide your IP when searching | Settings › Search and network › Hide my IP | One row instead of five. Good |
| Use it from the phone | Settings › Connectors › Phone access, scan the code | Fine. GPU actions (Run on RAM too) are blocked from the phone, on purpose |
| Find a setting | The search at the top of Settings | Finds every setting. The new Storage page shows what's on each drive |

Nothing here blocks the release. The two items worth doing next are in the 1.5.0 plan (model-load estimate; one
Models page for chat and picture models).
