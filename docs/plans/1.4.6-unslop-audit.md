# 1.4.6 - unslop audit (stage 4.1)

unslop by Damir Sokolovsky ([@heydamir](https://x.com/heydamir)), CC BY 4.0 - installed in the workspace's
`.claude/skills/unslop` after reading every file (its two scripts only run Playwright and ffmpeg locally).

How: the dev server (port 8010), a **1600x900 (16:9) window**, Home, a chat and Settings in Classic light and dark,
then Eclipse, Aurora, Sunrise and Terminal; plus a scan of all 4,573 CSS rules for the mechanical signs. The Claude,
ChatGPT, Grok and Gemini looks are judged by fidelity to their apps, so they are counted but not "unslopped".
Nothing is changed yet: these go into the redesign (4.3) and the /design before/afters (4.4).

**Verdict: light slop.** The app is mostly designed - no emoji anywhere in the interface, quiet chrome, one accent.
unslop's own rule for that case: *polish mode* - fix only what the audit found, keep the brand, palette and layout.

## What the audit found

| Sign | Where | Fix (from unslop) |
|---|---|---|
| The same chats twice | Home's "Continue" repeats the sidebar's chat list | One place; Home could show what's waiting (approvals, running, scheduled) instead |
| "Auto · Auto" side by side | the message bar: the access lock and the model picker, both "Auto" | Name each: e.g. the model's name, and the lock's own word |
| Placeholder that doesn't fit | "How can I help you today?" in the middle of a chat | "Reply…" in a chat; the greeting placeholder only on a new one |
| Cut-off status | sidebar footer: "Chat model · llama-server isn't r…" | A short state ("Model off") with the detail on hover |
| Uppercase tracked labels | 24 in shared UI - "TODAY", "PREVIOUS 7 DAYS", beta tags, list heads | Sentence case, normal tracking |
| Low-contrast icons | Classic dark: the suggestion chips' icons vanish in their dark gold circles; the model "Auto" is barely legible | The fitted `--*-text` tokens, as the contrast rule asks |
| Two looks that look the same | Eclipse and Classic dark are almost identical in the New interface (Eclipse's 11 gradient and glow rules show on few surfaces) | Give Eclipse its own character, or fold it into Classic - a choice that changes nothing is clutter |
| Glass and glow | Aurora: frosted-glass sidebar and cards (16 backdrop-blur rules) and a glowing outline on the message bar | Keep Aurora's sky (its atmosphere); solid raised surfaces and a hairline instead of glass and glow |
| A halo behind the headline | Sunrise (dusk): a large glowing ring behind "Good evening" | Keep only if it is the sun and stays still; otherwise remove |
| Brand twice | top-left logo and the footer "workspace · by Fuxion" | One - the credit already lives in About |
| Many top-bar icons | six icon buttons in a chat's top bar | Group the less-used ones under More |
| Heavy weights | 5 rules at 700+ (beta tag, counts, a list mark) | 500-600 |
| Three privacy places for search | Web search's Privacy mode (5 cards), "Search through Tor", the network route | One "How private is my searching" group (see the Settings inventory) |

Kept, on purpose: the greeting headline (unslop flags greetings, but "What should I call you?" is your product's
own touch - a suggestion only), Terminal's caret and Aurora's sky (a look's atmosphere, as the motion rule allows),
and Claude's text shimmer (the real app has it).

## Numbers from the CSS scan

Hue gradients: 47 shared, 42 in your own looks (Eclipse 16, Aurora 4), 10 in the AI looks, 20 in the secret theme.
Coloured glows: 29 shared, 17 own looks. Gradient text: 2 (Claude's shimmer). Infinite animations: 31 shared, 36 own
looks - each needs to pass the "means a state" rule in the motion check. Emoji in the interface: none.
